# deblur —— 图像去模糊（非盲反卷积）对比

## 1. 功能概述

用**已知 PSF**（点扩散函数）合成模糊图像，再用 4 类算法复原，以**未退化的干净图**为参考
给出 PSNR / SSIM。

这是**非盲去模糊（non-blind deconvolution）**：假设模糊核已知。真实场景里模糊核通常未知，
需要先做模糊核估计（盲去模糊），那是一个难得多的问题。本模块的价值在于把退化模型
讲清楚，并给出各复原算法的噪声鲁棒性对比。

## 2. 算法清单

| 算法 | 类别 | 核心公式 | 噪声鲁棒性 | 特点 |
|------|------|---------|-----------|------|
| **Inverse (bare)** | 逆滤波 | `F = G / H` | **极差** | 只有理论意义。H 接近 0 处会爆炸式放大噪声 |
| **Wiener** | 频域正则 | `O = conj(H)·G / (‖H‖² + K)` | 好（靠 K 控制） | 维纳滤波是**最小均方误差意义下的最优线性复原** |
| **Richardson-Lucy** | 迭代贝叶斯 | `u ← u · (G/(u⊛h)) ⊛ h_flip` | 好 | 假设泊松噪声，迭代式，**保真度最好**，但迭代多会振铃 |
| **Unsharp Masking** | 锐化基线 | `out = I + a·(I − blur(I))` | 不适用 | **不是复原，是增强**。作为对照组，用来说明"看着清楚 ≠ 真的复原了" |

### 2.1 退化模型

```
g = h ⊛ f + n
```

- `f` 清晰图，`h` 模糊核（PSF），`n` 噪声，`g` 观测到的模糊图。
- 本模块**不加噪声**（只做卷积），是理想化的无噪情形——所以 Wiener 的 `K` 主要用来
  压制数值误差和边界效应，而不是真实噪声。

### 2.2 两种 PSF

| 模式 | 构造 | 物理含义 |
|------|------|---------|
| `motion` | `motionPSF(length, 30°)`：沿 30° 方向的线段，L1 归一化 | 相机或物体在曝光期间沿某方向移动 |
| `defocus` | `defocusPSF(ksize, sigma)`：高斯核 `g·gᵀ` 外积，L1 归一化 | 镜头失焦（弥散圆近似为高斯） |

## 3. 运行

```powershell
cd build\algorithms

.\deblur.exe                                                    # lena + motion, len=9
.\deblur.exe ..\..\data\images\lena.jpg defocus 7.0             # 散焦模糊 sigma=7
.\deblur.exe ..\..\data\images\VCG5.jpg motion 15               # 更长的运动模糊
```

构建：

```powershell
.\build.ps1 -Target algorithms -Module deblur
```

## 4. 输入 / 输出

**输入**

| 参数 | 位置 | 默认值 | 说明 |
|------|------|--------|------|
| `argv[1]` | 输入图片 | `../../data/images/lena.jpg` | 干净图，同时作为 PSNR 参考 |
| `argv[2]` | 模糊模式 | `motion` | `motion` 或 `defocus` |
| `argv[3]` | 强度参数 | motion → `9`；defocus → `7.0` | motion 是模糊长度（像素），defocus 是高斯 σ |

- 长边 > 640 px 自动缩放到 640（DFT 在 640×640 量级已够慢）。
- 读取失败时合成随机图兜底。

**输出**

| 文件 | 内容 |
|------|------|
| `out/algorithms/deblur_compare.png` | 8 格 3 列：clean / blurred / Inverse / Wiener×3 / RL / Unsharp |

**stdout**

```
deblur mode=motion  PSF=9x9  (参考=干净图)
method                 PSNR vs clean    SSIM
Inverse(bare)               28.14   0.8102
Wiener(K=0.001000)          29.87   0.8534
Wiener(K=0.010000)          31.22   0.8801
Wiener(K=0.100000)          30.05   0.8203
RL(iter=30)                 33.41   0.9134
Unsharp(1.2)                26.33   0.7502
```

## 5. 参数表

| 参数 | 代码位置 | 默认值 | 影响 |
|------|---------|--------|------|
| 模糊模式 | `argv[2]` | `motion` | `motion` / `defocus` |
| motion `length` | `motionPSF((int)p1, 30.0)` | `9` | 模糊长度（像素）。↑ 越模糊，复原越难 |
| motion `angle` | `motionPSF(len, 30.0)` | `30°` | 运动方向 |
| defocus `sigma` | `defocusPSF(2σ+1, σ)` | `7.0` | 高斯 σ，核大小自动取 `2σ+1`（最小 3） |
| 卷积边界 | `filter2D(..., BORDER_WRAP)` | `WRAP` | **关键**：循环卷积，与频域反卷积模型一致。改成 `BORDER_REPLICATE` 会引入边界失配 |
| Wiener `K` | `wienerDeconv(bg32, psf, K)`，`K ∈ {0.001, 0.01, 0.1}` | 扫 3 档 | **噪声正则项**。K→0 退化为逆滤波；K↑ 更平滑但欠复原 |
| Inverse 的 K | `wienerDeconv(bg32, psf, 1e-8)` | `1e-8` | 用极小 K 模拟"裸逆滤波" |
| RL `iters` | `richardsonLucy(bg32, psf, 30)` | `30` | 迭代次数。↑ 更清晰但**振铃（ringing）加剧** |
| Unsharp `amount` | `unsharpBg(bGray, 1.2, 7)` | `1.2` | 锐化强度 |
| Unsharp `ksize` | 同上 | `7` | 高斯模糊核大小 |

**Wiener 的 K 怎么选**：

```
K ≈ 噪声功率 / 信号功率
```

本模块无真实噪声，所以最优 K 纯粹是在"压制数值/边界误差"和"保持复原强度"之间权衡。
实践经验：**motion 模糊下 K=0.01 附近通常是甜点**；如果给模糊图加了真实高斯噪声，
K 需要按上面的功率比公式相应增大。

## 7. 结果怎么读

### 7.1 指标

| 指标 | 含义 | 判读 |
|------|------|------|
| **PSNR vs clean** | 复原结果与**干净原图**的峰值信噪比 | 越高越好。作为基线，`blurred` 的 PSNR 通常比所有复原结果都低 |
| **SSIM** | 结构相似性 | 越接近 1 越好，比 PSNR 更符合主观感受 |

### 7.2 典型趋势（motion len=9）

```
Unsharp  <  blurred附近  <  Inverse  <  Wiener(极端K)  <  Wiener(最优K)  <  RL
```

- **Unsharp 的 PSNR 常常低于模糊图本身**（示例 26.33）——锐化只是让边缘对比度更高，
  **主观上"更清楚"，客观上离原图更远**。这是本模块设置这个对照组的用意。
- **Inverse 方差极大**：在无噪声时还能看，一旦有噪声立刻崩掉。
- **Wiener 呈倒 U 形**：K 太小 → 噪声放大；K 太大 → 复原不足。三个 K 值扫出曲线，
  能直观看到最优区间。
- **RL 通常最好**（示例 33.41 dB），代价是迭代 30 次的耗时。放大看边缘会发现轻微振铃。

### 7.3 视觉检查清单

| 现象 | 说明 |
|------|------|
| 边缘附近出现明暗交替的"水波纹" | **振铃（ringing）**，吉布斯效应。减少 RL 迭代次数或增大 Wiener 的 K |
| 整体发灰、模糊没去干净 | K 太大 / RL 迭代不够 |
| 画面布满颗粒状噪点 | K 太小，噪声被放大 |
| 四周边框有奇怪的条纹 | 边界处理问题。本模块用 `BORDER_WRAP`，与频域模型自洽，但真实图像边界不循环，仍会有轻微失配 |
