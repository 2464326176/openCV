# edge_detection —— 边缘检测算法横向对比

## 1. 功能概述

在同一张输入图上一次性跑完 **8 种边缘检测算子**，输出一张带标签的网格对比图 + 一张指标表。
覆盖从「一阶梯度算子」到「二阶零交叉算子」再到「最优化多阶段算法」的完整谱系，
用来直观回答一个工程问题：**我的场景到底该选哪个边缘算子**。

> 设计取向：所有响应都归一化到 `CV_8U [0,255]` 后再比较，保证"边缘密度""连续性"
> 这类跨算子的统计指标在同一量纲下才可比。

## 2. 算法清单

| 算子 | 类别 | 核心思想 | 抗噪性 | 边缘粗细 | 典型用途 |
|------|------|---------|--------|---------|---------|
| **Sobel** 3×3 | 一阶梯度 | `Gx/Gy` 离散微分 + 高斯平滑，取 `‖(Gx,Gy)‖` | 中 | 较粗（2 像素级） | 通用梯度、方向估计 |
| **Scharr** 3×3 | 一阶梯度 | 3×3 下的最优导数近似（`-3,0,3 / -10,0,10`） | 中 | 同 Sobel | 需要旋转对称性的精细梯度 |
| **Prewitt** 3×3 | 一阶梯度 | 均匀权重微分核，无中心加权 | 中 | 同 Sobel | 教学 / 快速梯度 |
| **Laplacian** k=3 | 二阶 | 二阶导零交叉，本模块取 `abs()` 后归一化 | **差**（噪声放大 2 倍） | 细（1 像素） | 需配合前置降噪使用 |
| **LoG** σ=3 | 二阶 | 先 `GaussianBlur(5,5,σ=3)` 再 Laplacian | 好 | 中等 | 斑点检测、尺度化边缘 |
| **DoG** 1.0→3.0 | 二阶近似 | 两个不同 σ 的高斯响应相减，近似 LoG | 好 | 中等 | 角点/斑点，SIFT 的基础 |
| **Canny** (100,200) | 最优化 | 降噪 → 梯度 → NMS → 双阈值滞后连接 | **好** | 细（单像素） | 工业检测、轮廓提取首选 |
| **Canny-Otsu** | 最优化 | 用 Otsu 自动阈值 `t` 推出 `low=0.5t, high=1.33t` | 好 | 细 | **自适应**，换图不用手调阈值 |

> **为什么二阶算子要先高斯？** Laplacian 是二阶微分，对高频噪声的放大是梯度算子的一阶
> 再微分，噪声会被平方级放大。所以 LoG/DoG 都把"平滑"内建进算子，而裸 Laplacian
> 必须你自己先 `GaussianBlur`。

## 3. 运行

```powershell
# 从 algorithms 的构建输出目录运行（保证 ../out/algorithms 相对路径正确）
cd build_algo_ALL\algorithms

.\algo_edge_detection.exe                                        # 默认 data/images/lena.jpg
.\algo_edge_detection.exe ..\..\data\images\VCG5.jpg             # 指定图片
```

构建该模块：

```powershell
.\build.ps1 -Target algorithms -Module edge_detection
```

## 4. 输入 / 输出

**输入**

| 参数 | 位置 | 默认 | 说明 |
|------|------|------|------|
| `argv[1]` | 输入图片路径 | `../../data/images/lena.jpg` | 任意 `imread` 可读格式 |

- 长边 > 900 px 会自动 `INTER_AREA` 缩放到 900，避免大图网格拼接过慢。
- 输入为空时自动合成随机图，保证 demo **100% 可跑**。

**输出**

| 文件 | 内容 |
|------|------|
| `out/algorithms/edge_detection_compare.png` | 1 张输入 + 8 张结果，3 列网格，每格带标签条 |

**stdout 指标表**

```
method                          density avg_comp_size
Sobel(3x3)                       12.34%         45.2
...
```

## 5. 参数表

| 参数 | 代码位置 | 默认 | 影响 |
|------|---------|------|------|
| Sobel / Scharr / Prewitt 核 | `gradientMag()` 内联 | 固定 3×3 | 换成 5×5 Sobel 可降噪但边缘更粗 |
| LoG 的 σ | `GaussianBlur(gray, gblur, Size(5,5), 3.0)` | `3.0` | σ↑ → 尺度变大，只留粗边缘 |
| LoG 的 `ksize` | `Laplacian(..., 3)` | `3` | 只能取 1/3/5/7（奇数） |
| DoG 的两个 σ | `GaussianBlur(gray, g1, Size(), 1.0)` / `3.0` | `1.0` / `3.0` | 比值越接近 1 → 频带越窄 |
| Canny 双阈值 | `Canny(gray, canny, 100, 200)` | `100 / 200` | 高低比建议 **2:1 ~ 3:1** |
| Canny-Otsu 系数 | `low = 0.5*t`, `high = 1.33*t` | `0.5 / 1.33` | 想更"干净"就把 low 系数调高 |
| 边缘判定阈值 `thr` | `edgeDensity(gray2, 40)` | `40` | 仅影响统计指标，不影响出图 |

| 数据 | 路径 | 说明 |
|------|------|------|

## 7. 结果怎么读

两个自定义无参考指标（因为边缘检测通常没有 GT）：

| 指标 | 定义 | 怎么判断好坏 |
|------|------|------------|
| **density**（边缘密度） | 响应 > 40 的像素占比 | **不是越高越好**。过高 = 把噪声/纹理当成边缘；过低 = 漏检 |
| **avg_comp_size**（平均连通域规模） | 阈值化后每个连通分量的平均面积（忽略 < 3 px 的孤立点） | **越大越好**，代表边缘连续、不碎裂 |

**典型观察（lena.jpg）**：

- `Sobel/Scharr/Prewitt` 三者视觉接近，Scharr 在斜边上的响应最均匀（旋转对称性最好）。
- `Laplacian` 密度通常最高但连续性好不到哪去——它在纹理区疯狂响应，是"噪声放大镜"。
- `Canny` 系列密度最低、连续性最好：**单像素宽 + 滞后连接**天然抗碎裂。
- `Canny-Otsu` 换个图也不用调参，是自动化流水线里的默认选择。

**选型速判**：

```
要单像素细边缘 + 抗噪      → Canny（有调参条件）或 Canny-Otsu（无调参条件）
要梯度方向参与后续计算      → Sobel / Scharr
要检测斑点而非线段          → LoG / DoG
只是想看个大概              → Sobel（最快）
```
