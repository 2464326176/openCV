# frequency_domain —— 频域分析与滤波

## 1. 功能概述

把图像搬到**频域**做四件事：看谱、低通、高通、去周期噪声（陷波）。
输出 6 格对比图 + 三个 PSNR / 一个边缘密度指标。

频域视角的价值在于：**有些在空间域极难描述的问题（如周期性条纹噪声），在频域就是几个孤立的亮点**，
挖掉即可。

## 2. 算法清单

| 功能 | 实现 | 数学表达 | 效果 |
|------|------|---------|------|
| **幅值谱** | `dft` → `magnitude` → `log(1+m)` → 象限交换 | `‖F(u,v)‖` | 看清图像的频率构成 |
| **高斯低通** | 中心化高斯掩膜 `H = exp(−D²/2σ²)` | `G·H` | 平滑去噪，去掉高频细节 |
| **高斯高通** | `H = 1 − 低通掩膜` | `G·(1−H)` | 保留边缘与细节，压掉平坦区 |
| **陷波带阻** | 在噪声峰位置把 `H` 置 0 | `G·H_notch` | **精准去除周期性噪声**，几乎不伤其他频率 |

### 2.1 为什么要做象限交换（fftshift）

OpenCV 的 `dft` 输出**未中心化**：`F(0,0)`（直流/低频）在**左上角**，
低频能量分布在四个角。

- **看谱**需要中心化 → 交换象限，把低频移到图中央（视觉上才符合直觉）。
- **做滤波**时掩膜必须与 `dft` 的布局一致 → 所以要**先构造中心化掩膜，再交换象限**变回
  未移位布局，才能与 `F` 逐元素相乘。

本模块两个函数各司其职：

| 函数 | 用途 |
|------|------|
| `magnitudeSpectrum()` | 内部做象限交换，**只用于显示** |
| `swapQuadrants()` | 通用的象限交换工具，**滤波前把中心化掩膜转回未移位布局** |

> 这是频域处理最常见的 bug 来源：掩膜布局与 `dft` 输出对不上，结果就是"滤波没生效"
> 或者"图像被打散成奇怪的条纹"。

### 2.2 周期噪声与陷波

```
空间域：  noisy = clean + A·sin(2π(fx·x + fy·y))
频域：    在 (±fx·W, ±fy·H) 处出现 4 个孤立亮点（共轭对称 → 实际是 2 对）
处理：    把这些点及其邻域置 0（陷波）
```

本模块叠加的是 `amp=42, fx=0.08, fy=0.05` 的正弦纹波。因为**参数已知**，
所以陷波位置可以直接算出来（真正的工程场景需要先在谱上找亮点，或做自动峰值检测）。

## 5. 参数表

| 参数 | 代码位置 | 默认值 | 影响 |
|------|---------|--------|------|
| **DFT 尺寸** | `getOptimalDFTSize(gray.rows/cols)` | 自动 | **关键优化**。DFT 在 2、3、5 的倍数的尺寸上快得多，用此函数补齐 padding |
| 低通 σ | `gaussFilterMask<true>(H, W, 40.0)` | `40.0` | σ↑ 保留更多低频（更模糊）；σ↓ 更接近原图 |
| 高通 σ | `gaussFilterMask<false>(H, W, 30.0)` | `30.0` | σ↑ 只有很高的频通过（边缘更细）；σ↓ 保留更多中低频 |
| 周期噪声幅度 | `double amp = 42.0` | `42.0` | 叠加的正弦波振幅（0~255 尺度） |
| 周期噪声频率 `fx` | `double fx = 0.08` | `0.08` | 水平方向频率（**归一化频率**，周期 = 1/0.08 ≈ 12.5 px） |
| 周期噪声频率 `fy` | `double fy = 0.05` | `0.05` | 垂直方向频率（周期 ≈ 20 px），与 fx 组合决定条纹倾角 |
| 陷波半径 | `for (dy = -3..3) for (dx = -3..3)` | `±3` | 挖掉的邻域大小。**太小去不干净，太大伤及有用频率** |
| 高通边缘统计阈值 | `countNonZero(hg > 40)` | `40` | 仅影响指标，不影响出图 |

> **归一化频率的含义**：`fx = 0.08` 表示每像素相位推进 `0.08` 个周期。
> 换算成像素周期：`1 / 0.08 = 12.5 像素`。调大 `fx` → 条纹更密。

## 7. 结果怎么读

### 7.1 幅值谱怎么看

中心是**低频**（图像的整体轮廓、大片平坦区），向外是**高频**（边缘、纹理、噪声）。

| 谱的形态 | 说明 |
|---------|------|
| 能量集中在中心一小团 | 图像以平滑区域为主 |
| 能量沿某个方向呈亮线 | 图像有**强方向性纹理**（如布料、栅栏） |
| 出现对称的孤立亮点（远离中心） | **周期性噪声**，就是陷波要挖的目标 |
| 谱整体发白、铺满 | 图像是噪声或极高频纹理 |

### 7.2 指标

| 指标 | 定义 | 判读 |
|------|------|------|
| **lowpass PSNR(clean)** | 低通结果 vs 原图 | 数值不会太高（低通本来就丢高频）。它衡量的是**低通造成的失真程度**，不是"去噪效果" |
| **highpass edge density** | 高通结果中 > 40 的像素占比 | 反映图像的**边缘/纹理丰富度**。baboon 会显著高于 lena |
| **notch PSNR(clean)** | 陷波去噪结果 vs 原图 | **核心指标**。应显著高于 `noisy PSNR` |
| **noisy PSNR(clean)** | 加噪图 vs 原图 | 基线。示例 22.15 dB |

**典型结果解读**（示例数值）：

```
noisy  22.15 dB   ← 加了周期噪声，质量明显下降
notch  34.87 dB   ← 陷波把噪声挖掉，恢复 12+ dB
```

**这个 12 dB 的跃升就是频域方法的威力所在**——同样的周期噪声，用空间域的高斯/中值滤波
基本无解（因为噪声频率与图像高频重叠），而在频域就是"挖掉几个点"。

### 7.3 视觉检查

| 现象 | 说明 |
|------|------|
| `notch removed` 上还残留条纹 | 陷波位置或半径不对。检查 `fx`/`fy` 是否与实际噪声频率一致，或把 `±3` 调大 |
| `notch removed` 出现同心圆波纹 | 陷波挖得太狠（半径过大），产生了振铃。调小半径 |
| 低通后图像发虚 | 正常。σ=40 是相当强的低通 |
| 高通结果一片黑，只有边缘是亮的 | 正确。高通就是干这个的 |
| 谱图看着像噪声、看不出结构 | 输入可能是随机合成图（读取失败的兜底分支） |
