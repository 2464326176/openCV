# beauty — 美颜算法 demo

## 算法流水线

```
input BGR
   │
   ▼
┌───────────────────────────────────────────────────┐
│ frequency separation 磨皮  │ 双边保边 low + (原−low) high × (1−s) │
└───────────────────────────────────────────────────┘
                       ▼
┌───────────────────────────────────────────────────┐
│ Gamma 提亮 (γ=0.85)         │
└───────────────────────────────────────────────────┘
                       ▼
┌───────────────────────────────────────────────────┐
│ YCrCb Y 通道 CLAHE          │ 局部对比恢复，色彩不偏 │
└───────────────────────────────────────────────────┘
                       ▼
┌───────────────────────────────────────────────────┐
│ 磨皮 (median + bilateral 2) │ 与原图 6:4 混合防过度涂抹 │
└───────────────────────────────────────────────────┘
                       ▼
┌───────────────────────────────────────────────────┐
│ Unsharp Mask 锐化 (amount=0.6)│ 高频残差回加，提升五官清晰度 │
└───────────────────────────────────────────────────┘
                       ▼
                output BGR
```

## 磨皮：频率分离 (Frequency Separation)

这是专业修图里常用的"保边磨皮"：

1. `low = bilateralFilter(in, d=9, σ_c=75, σ_s=75)`：低频 = 皮肤基底色
2. `high = in − low`：高频 = 痘印/细纹 + 五官边缘
3. 高频抑制 `high' = high × (1 − s)`：s ∈ [0,1]，s 越大磨皮越猛
4. `out = low + high'`

**核心 idea**：五官边缘是"大尺度高频"，痘印是"小尺度高频"，简单的全局高频
衰减会让痘印明显变弱而五官还能保住。专业修图里会把皮肤 mask 用 dodge/burn 再
处理，这里简化为全局应用。

## 提亮 & 磨皮 & 锐化

- **Gamma 提亮**：`J = I^γ`，γ≈0.85 让暗部往上抬；γ 太小会让暗部过曝
  发灰。组合 CLAHE 是因为 Gamma 会把整体照亮，CLAHE 把局部对比拉回来。
- **磨皮**：`medianBlur(3) → bilateralFilter(5)` 迭代 2 次，再与原图 6:4 混合。
  中值先去掉椒盐噪点，双边再保边平滑。混合比例可调。
- **Unsharp Mask**：`sharp = in + amount · (in − blur)`，`blur = GaussianBlur(in, σ=1.5)`。
  把高频残差按 `amount` 加回原图，"看起来更锐"但本身像素层面并没有真正增加细节。

## 数据来源

默认 `data/images/lena.jpg`，可换 `VCG*.jpg` 等人物图：

```powershell
cd out\algorithms
.\algo_beauty.exe                                          # lena 默认
.\algo_beauty.exe ..\..\data\images\VCG5.jpg 70           # 自定义图与磨皮强度
```

输出 `out/algorithms/beauty.png`，6 张并排，从 input 一步步到 final sharp。

## 局限

- 没有 skin mask，背景也被磨 → 工程化必须先做皮肤分割 (YCbCr + HSV
  综合判断或 DL 模型)。
- 磨皮强度 `s` 没自适应，对低照度输入应自动增大 (因为暗部噪点视觉上更明显)。
- 没做肤色保色 → 应该在 YCrCb 上分离肤色，保护色相通道。

## 扩展建议

- 接入 `models/face_detection_yunet_2023mar.onnx`：先检测人脸，只磨人脸框内；
- 引入 skin mask：`Y∈[0,255], Cr∈[133,173], Cb∈[77,127]`，按 mask 只磨皮肤；
- 在磨皮前先做 `denoiseNLM` 降噪，避免把噪点放大成"新"坑；
- 加 SeNet 风格的"自然美颜"NN 模型做最终对比。
